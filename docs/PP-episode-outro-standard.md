# PP video — STANDING OUTRO standard (every episode)
*Captured 2026-07-22 from Jodie. This is a workflow RULE for the plugin (Cowork + Claude Code). EP05 was missing all of this — it's now mandatory on every episode.*

*Copied to the Drive by Cowork on 26 Jul 2026 because Claude Code could not see it: it existed only in the claude.ai project, while the pp-episode-script skill names it as a base standard. That was a dangling reference. It now lives here so both sides can read the same words.*

Every episode must end with a proper **spoken outro by Gordon** — he never just stops talking dead at the last article line. The outro is a STANDING structure; only the one-line topic wind-down changes per episode. It comes **after** the final article line and **before** the end card.

## The outro Gordon always speaks (in order)
1. **A short, warm wind-down** of the episode's topic — one or two lines that make the ending feel finished (not a hard cut). *(This line is episode-specific.)*
2. **Point to the FREE E-BOOK** — a soft call to action: name the e-book, "the link's below this video," keep it beside you on race day. No hype, no promises.
3. **Responsible-gambling line — ALWAYS** — verbatim intent: **"And remember — never bet more than you can afford to lose."** This spoken line is mandatory every episode (in addition to the on-screen warranty slide).
4. **Warm sign-off** — e.g. "That's me for this week. Look after yourself, trust your form study, and I'll **see you soon**." Use **"see you soon"** (not a strict weekly promise). Do **NOT** end on "Good punting", and do **not** add a "this is a game" line — Jodie cut both.

## Then, at the very end (assembly)
- **End card** — real e-book cover + free e-book link line (no responsible-gambling elements here).
- **Music** — the "Sleeves Full of Aces" **sting RETURNS at the end card**, then sits **soft under the warranty slide** (per the locked audio recipe). The end must never be silent.
- **Warranty slide** — standing slide, verbatim, soft music bed, ~3s tail.

## Render / voice
- The outro is rendered with the **same avatar, same voice, same grandstand background** as the body — either included in the main HeyGen render or as a short appended outro segment. Numbers as words.

## Approval (important)
- The outro is **added content beyond the article**, so the STANDING outro wording must be **approved by Hugh once** (Gmail draft to hugh@equest.com.au, cc jlralph@gmail.com). After that one approval it's **reusable verbatim every episode** — only the episode-specific wind-down line (item 1) is new each time, and stays within the approved shape.
- Brand rules still apply: no hype, no promises/guarantees, never any "tax" framing.

## Why this exists
EP05 v1 ended with Gordon stopping mid-air, no e-book mention, no sign-off, and no end music. This rule prevents all of that, permanently.
