## warranty-slide.html — LOCKED, APPROVED (Jodie, EP02 v2, 2026-07-20)
The final screen of every PP episode. Identical every time. Layout is approved
exactly as-is: PP logo top, warranty text, then at the bottom the large
"WHAT ARE YOU PREPARED TO LOSE TODAY?" heading with the support line beneath.
No sales@equest.com.au on the video slide (that's e-book only). No orange.
1.2s fade-in, then hold.

Do NOT edit this file for a new episode — it carries no per-episode text.
Copy it into `PP-EPxx/overlay/export/` alongside `pp-anim.js` and `assets/logo.png`,
render with `scripts/render_card.py`, composite as a full-frame card (no keying).

**Compositing rule (learned EP02 v2→v3):** the card underneath it must stay
SOLID while this one fades in. If the previous card fades out at the same time,
both are briefly semi-transparent and the presenter shows through for ~0.5s.
Hold the outgoing card past the incoming card's fade-in.

## ebook-marketing-page.html + ebook-logo.png + marketing-hero.png
The reusable LAST page of every PP e-book (approved EP02, 2026-07-20). Copy all
three into the book's folder and paste the block before </body>. All text is
real HTML — the book's global `p { text-align: justify }` will left-align any
centred single-line <p> unless it carries its own text-align:center (bit us
once). Logo is the chip cropped from the EP02 cover (rounded-corner alpha).

**E-book header-logo pattern (approved 2026-07-20):** `ebook-logo-white.png`
(orange icon + charcoal text, transparent) goes on every content page via
`@page { @top-right { content: url('ebook-logo-white.png'); image-resolution: 220dpi; } }`.
Suppress it on the marketing page (it has its own big chip) by wrapping that
block in `page: marketing` and `@page marketing { @top-right { content: ""; } }`.
The cover page suppresses automatically via `@page :first { margin: 0 }`.

## youtube-banner-template.html (+ render_still.py)
Channel banner, 2560x1440, approved 2026-07-20. Build:
`python scripts/render_still.py banner.html out.png 2560 1440` from the folder
holding banner-bg.png + pp-youtube-icon-800.png.
SAFE AREA is the centre 1546x423 (x 507-2053, y 508-931) — everything visible
on phones/TVs. Verify by measuring element rects in Playwright, not by eye.
SCRIM LESSON (three attempts): a part-width band shows hard horizontal lines at
its left/right edges; a radial pools into a visible dark oval against smooth
sky. What works is a FULL-BLEED vertical linear gradient (no side edges, no
shape), darkest across 35-65% height to match the safe strip.
Channel-wide assets live in `PP Videos/Channel-Branding/`, not episode folders.

## youtube-thumbnail-template.html (+ pp-logo-on-dark.png)
Episode thumbnail, 1280x720, approved 2026-07-20 (EP02 "Trifectas Done Right").
Build: `python scripts/render_still.py thumbnail.html out.png 1280 720` from a
folder holding thumb-frame.png + pp-logo-on-dark.png.
FRAME PICKING (do this properly — it decides the thumbnail):
  1. Sample only MCU stretches that are clear of BOTH card cues and b-roll
     slots — cross-check the pass-B cue list. A card behind the scrim ghosts
     through (an early EP02 pick had "14%" showing behind the headline).
  2. Reject mid-blink and mid-word mouth shapes; a warm closed-mouth smile with
     eyes to camera beats a neutral stare.
  3. Note whether the panel push was active — he's right-of-centre during a
     push, centred otherwise, which changes the crop offsets.
LOGO: use `pp-logo-on-dark.png` (orange icon + WHITE wordmark, transparent) on
dark art; `ebook-logo-white.png` (charcoal wordmark) is for white pages only.
SCRIM: left-to-right gradient spanning FULL height (no top/bottom edges).
CHECKS: headline must read at 120px wide; PNG must stay under YouTube's 2 MB.
COMPLIANCE: strategy/curiosity framing only — never guarantees or inducements.
